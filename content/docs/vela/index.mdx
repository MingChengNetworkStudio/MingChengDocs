# Vela 应用开发文档

本套文档面向 **Xiaomi Vela**（NuttX）上的应用开发者，按开发形态分为三大部分：

| 分类 | 适用场景 |
| ---- | ---- |
| **[Lua 应用开发](/docs/vela/LUA)** | Lua 5.4 + LVGL 的应用与表盘开发：入门、UI 控件、能力模块、Lua 标准库与实战 |
| **[快应用 Feature](/docs/vela/quickapp)** | Quick App Feature API：通过 `require('system.xxx')` 调用网络、蓝牙、多媒体、文件、传感器等能力 |
| **[附录](/docs/vela/appendix)** | NSH Shell 命令参考、系统与固件配置（`/etc`、ota、recovery）及社区资料 |
