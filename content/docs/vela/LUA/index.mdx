Vela 的 Lua 运行时基于 **Lua 5.4**（NuttX 12.3.0 / Xiaomi Vela 环境），通过 LVGL 提供 UI 能力，并以模块化方式暴露设备能力（dataman 数据订阅、topic 消息、animengine 动画、vibrator 振动、navigator 导航等）。典型用途是**手表表盘**与轻量 Lua 应用。

<Callout type="info">
本分类为融合文档：以 Vela 官方 Lua 文档（docs-lua）为骨架（全部 API / 表格 / 示例完整保留），织入洛汐文档库（https://docs.luoxe.cn/ ）的实战内容，社区补充以「社区补充」小节标注。
</Callout>

### Vela 能力模块

| 模块 | 能力 |
| ---- | ---- |
| activity | 页面状态管理（isShown） |
| animengine | 属性动画引擎（x/y/rotate/opacity/scale） |
| dataman | 数据订阅（subscribe/pause/resume） |
| navigator | 页面导航（finish） |
| screen | 屏幕控制 |
| topic | 消息订阅（subscribe → unsubscribe/frequency） |
| vibrator | 触觉反馈（start/cancel + 15 种模式） |
