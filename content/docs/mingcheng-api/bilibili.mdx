> 模块类型：service ｜ 基础路径：`/api/v2/bilibili` ｜ 鉴权：设备 APIKey

BiliMax **设备桥接**：重计算（视频转码等）在手机端执行，服务器只做转发。手机端主动建立 WebSocket 长连注册上来，App 的 HTTP 请求经网关通过该连接同步 RPC 到手机，并回传 JSON 或二进制产物（产物不落盘）。

<Callout type="info">
全部端点使用设备 APIKey（查询 `key`/`Key` 或请求头，路径含 `:appname`）。仅 `createTask` 扣配额，其余 noQuota。JSON 走统一信封 `{ "status":200, "result":<数据> }`；产物（info / audio / frame）返回**原始字节**。
</Callout>

---

## 一、手机端接入（WebSocket）

执行转码的手机端用设备 APIKey 主动建立 WebSocket 长连：

```
wss://<网关域名>/api/v2/bilibili/connectDevice/<appname>?key=<设备apiKey>
```

**接入流程：**

1. 建立 WebSocket（网关完成 apikey 鉴权后透传升级）。
2. 连接成功后服务器先发文本帧：

   ```json
   { "v": 1, "op": "ready" }
   ```

3. 设备**必须在 10 秒内**发送首帧 hello（文本 JSON）：

   ```json
   { "v": 1, "op": "hello", "info": { /* 设备信息 */ } }
   ```

   服务器校验后回 `{ "v":1, "op":"hello_ack" }`；校验失败关闭连接（4002）。

4. 之后设备监听 RPC 请求并回复。

**RPC 帧协议（v1）：**

- 服务器 → 设备（请求，文本 JSON）：

  ```json
  { "v": 1, "id": "<请求id>", "method": "GET|POST", "path": "/api/...", "body": {} }
  ```

- 设备 → 服务器（JSON 结果，文本）：

  ```json
  { "v": 1, "id": "<同上>", "status": 200, "body": { } }
  ```

- 设备 → 服务器（二进制产物）：先发文本头，紧跟**一个二进制帧**承载字节：

  ```json
  { "v": 1, "id": "<同上>", "status": 200, "contentType": "<mime>", "length": 12345, "binary": true }
  ```

<Callout type="info">
保活：响应服务器 ping（自动 pong）；单帧 ≤ 64MB；RPC 约 15s 超时。设备需实现被转发的内部 HTTP：`GET /api/status`、`POST /api/createTask`、`GET /api/task/{id}` 及产物文件路径。
</Callout>

## 二、App 侧 HTTP（客户端）

### 设备在线 / 状态

| 方法 | 路径 | 说明 / result |
|---|---|---|
| GET | `/api/v2/bilibili/getDevice/:appname?key=` | 无绑定设备：`{ "online": false }`；在线：设备信息对象 |
| GET | `/api/v2/bilibili/status/:appname?key=` | 透传手机端 `GET /api/status` 的原始返回（在线状态） |

### 任务

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/v2/bilibili/createTask/:appname?key=` | 转发手机 `POST /api/createTask`（body 经校验）；**扣配额**；返回手机任务体 |
| GET | `/api/v2/bilibili/task/:appname/:taskId?key=` | 转发手机 `GET /api/task/{id}`，返回任务状态；404 任务不存在或已过期 |

### 产物（原始字节，非信封）

| 方法 | 路径 | 内容 |
|---|---|---|
| GET | `/api/v2/bilibili/task/:appname/:taskId/info?key=` | `info.json`（JSON） |
| GET | `/api/v2/bilibili/task/:appname/:taskId/audio?key=` | `audio.mp3`（音频二进制） |
| GET | `/api/v2/bilibili/task/:appname/:taskId/frame/:name?key=` | 帧图片（`:name` 为规范化产物名，图片二进制）；`Cache-Control: private, max-age=60` |

<Callout type="warn">
产物不存在 → 404；设备未连接 → 503；转发失败 → 502。
</Callout>
